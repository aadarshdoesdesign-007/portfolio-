# Aadarsh R — Design Portfolio & Research Archive

Personal portfolio, interactive digital archive, and design research showcase of **Aadarsh R** (UI/UX, Product & Communication Designer).

Live repository: [https://github.com/aadarshdoesdesign-007/portfolio-](https://github.com/aadarshdoesdesign-007/portfolio-)

---

## Overview

A typography-led editorial portfolio and design archive built with Next.js 14 (App Router), TypeScript, and Tailwind CSS.

### Key Features

- **Global Design Lens System**: Orthogonal design system featuring 7 distinct stylistic perspectives:
  - `Default` — Master editorial design with refined typography and microinteractions.
  - `Swiss` — International Typographic Style (rigid grid, grotesque typography, sharp 0px corners, high contrast).
  - `Brutalist` — Raw Neo-Brutalist & Hacker aesthetic (monospace, 2px borders, 4px solid drop shadows).
  - `Editorial` — High-fashion print magazine & literary serif typography (Garamond/Georgia italic, Roman numerals).
  - `Maximalist` — Kinetic pop-art energy with offset drop shadows and vibrant badges.
  - `Experimental` — Cybernetic telemetry HUD with scanlines, coordinate readouts, and dashed borders.
  - `Minimal` — Ultra-restrained, whisper-quiet typography and pure whitespace.
- **6-Colour Global Theme System**: Orthogonal palette featuring Black (default initial load), Orange (#F7480B), Blue (#5E4C9B), Green (#4D6940), Brown (#5B2616), and Purple (#97319B).
- **Interactive Pixel Portrait**: Smooth canvas-based resolution on hover/tap.
- **Hero Statement & Mountain Landscape Reveal**: Fluid clamp typography with an inline editorial hover reveal of an alpine mountain landscape.
- **Projects Archive & Filter**: 6 curated projects across Product Design, UI/UX, Information Visualization, and Research with SVG schematic diagrams, category filtering, and modal case studies.
- **Project Search (Cmd+K)**: Instant keyboard-driven fuzzy project search modal.
- **6-Column Grid Overlay**: Accessible via the 'g' keyboard shortcut.
- **Vita & Timeline**: 3-column masonry curriculum vitae with achievements (including ACM SIGCHI LLM Interfaces Hackathon 2nd Place / Runner-Up).

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/aadarshdoesdesign-007/portfolio-.git
cd portfolio-
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### Production Build

```bash
npm run build
npm run start
```
